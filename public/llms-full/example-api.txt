# Buildings AI Developer Kit

> Agent-ready documentation for the Schneider Electric EcoStruxure Building Data Platform APIs (REST API, GraphQL API, Event Hubs), generated from the official product documentation. Documentation only: this kit contains no live data.

Calling the APIs requires authentication (see the Authentication pages). Live building data is only available through the authenticated APIs or the separate, authenticated API MCP server, never through this kit. Examples use fictional identifiers.

# Authentication

> **Placeholder content.** This page is fictional. It is replaced by the first real export.

Requests carry a bearer token in the `Authorization` header:

```http
GET /api/v1/sites HTTP/1.1
Host: api.example.com
Authorization: Bearer <token>
```
