# Building Data Platform API documentation

Official documentation for the Schneider Electric EcoStruxure™ Building Data Platform APIs,
as plain markdown. Documentation only: this skill contains no live data and no credentials.

## How to use these docs

1. **Find the page first.** Use the index below, or search all pages from this skill's
   folder:

   ```bash
   python scripts/search_docs.py "historical values pagination"
   ```

   It prints the best-matching pages with the lines that matched.
2. **Read the page before writing code.** Use endpoints, parameters, field names, GraphQL
   types and enum values exactly as documented. Never guess a name that is not in the docs;
   if something is missing, say so.
3. **Authenticate first.** Every API call needs a token; follow the *Authentication* page of
   the API you use (REST API or GraphQL API).
4. **Test against UAT.** The API introduction pages list the UAT environment that partners
   and ISVs use for testing. Use production only when the user asks for it.
5. **Avoid deprecated features.** Pages marked *(deprecated)* describe features kept for
   existing integrations. Do not use them in new code.
6. **Examples use fictional identifiers.** Never present them as real IDs.
7. **Live data needs credentials.** This skill cannot read or change any building data.
